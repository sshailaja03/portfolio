# Shailaja Singh — Software Engineering Portfolio

The source code for my personal developer portfolio, built to showcase software engineering projects, technical skills, and experience.

**Live site:** [shailaja-singh.vercel.app](https://shailaja-singh.vercel.app)

## What this portfolio demonstrates

- Interactive, responsive developer experience
- Project-focused presentation of software engineering work
- Reusable React components and typed application code
- Motion and 3D interactions for a polished interface
- Modern Next.js application structure
- Production deployment through Vercel

## Tech stack

| Area | Technologies |
|---|---|
| Framework | Next.js 16, React 19 |
| Language | TypeScript |
| Styling | Tailwind CSS |
| Motion | Framer Motion, GSAP |
| 3D | Three.js, React Three Fiber, Drei |
| Forms & Validation | React Hook Form, Zod |
| Icons & UI | Lucide React |
| Deployment | Vercel |

## Run locally

```bash
git clone https://github.com/sshailaja03/portfolio.git
cd portfolio
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
