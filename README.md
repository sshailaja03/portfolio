# Shailaja Singh — Developer Portfolio

The source code for my personal developer portfolio, built to present my projects, technical skills, and experience in one accessible place.

**Live site:** [shailaja-singh.vercel.app](https://shailaja-singh.vercel.app)

## Highlights

- Responsive project and experience sections
- Dedicated presentation for software-development work
- Optimised layouts for desktop and mobile
- Reusable components and typed application code
- Deployment through Vercel

## Tech stack

- Next.js
- React
- TypeScript
- CSS
- Vercel

## Run locally

```bash
git clone https://github.com/sshailaja03/portfolio.git
cd portfolio
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

- **Sofia Chess Engine** — UCI-compatible C++17 chess engine using iterative deepening, alpha-beta pruning, and quiescence search
- **DevLink** — Full-stack developer project showcase with authentication and project management
